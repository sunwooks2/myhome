01

프로젝트 개요

목적

마이옥션에 개인 계정으로 등록해 둔 관심물건 목록을 자동으로 수집하여, 별도 웹 화면에서 목록·지도 형태로 통합 관리한다. 물건별로 권리분석 메모, 임장 기록, 입찰 준비 상태를 개인이 직접 추적할 수 있도록 지원하는 것이 최종 목표다.

배경

마이옥션 자체 화면은 목록 위주라 여러 물건을 지역·가격대별로 공간적으로 비교하거나, 규제구역·개발호재를 지도 위에 겹쳐 보거나, 개인 메모와 입찰 전략을 함께 기록하기 어렵다. 이 프로젝트는 그 틈을 메우는 개인용 보조 도구다.

범위

  • 개인 단일 사용자 전용 웹앱. 로컬 PC 또는 개인 홈서버/NAS에 배포하는 것을 전제로 한다.
  • 마이옥션 데이터는 읽기 전용으로만 수집한다. 마이옥션에 데이터를 쓰거나 입찰을 대행하지 않는다.

범위 제외 (Out of Scope)

  • 실제 입찰 대리 제출 및 전자입찰 자동화
  • 다중 사용자 계정, 공유·협업 기능
  • 법률 자문 수준의 자동 권리분석 판단 (사용자 메모를 위한 보조 필드만 제공)
  • 굿옥션·스피드옥션·지지옥션 등 타 경매정보 사이트 연동 (11장 향후 확장에서 재검토)
02

용어 정의

이 문서 전반에서 사용하는 경매 용어를 정리한다. 화면 설계와 데이터 모델을 이해하는 데 필요한 최소한의 정의다.

감정가
감정평가사가 산정한 물건의 시장가치. 최초 최저매각가격 산정의 기준이 된다.
최저매각가격
해당 매각기일에 입찰 가능한 최저 금액. 유찰될 때마다 통상 20~30%씩 저감된다.
유찰
입찰자가 없거나 낙찰 요건을 충족하지 못해 매각이 성립되지 않은 것. 유찰 횟수가 많을수록 최저가가 낮아진다.
매각기일
법원이 지정한 입찰 진행일.
낙찰가율
실제 낙찰금액을 감정가로 나눈 비율. 지역·물건종류별 시세 판단 지표로 쓰인다.
대항력
임차인이 임대차 관계를 낙찰자에게 주장할 수 있는 권리. 말소기준권리보다 앞서 전입신고와 점유를 갖췄을 때 성립한다.
말소기준권리
등기부상 권리 중 경매로 소멸되는 기준이 되는 권리(보통 최선순위 저당권·가압류 등). 이보다 늦은 권리는 낙찰과 동시에 소멸한다.
인수권리
낙찰자가 낙찰 후에도 떠안아야 하는 권리. 대항력 있는 임차보증금, 유치권 등이 해당한다.
매수신청보증금
입찰 시 제공해야 하는 보증금. 통상 최저매각가격의 10%이며, 재매각 물건은 20~30%로 상향되는 경우가 있다.
특별매각조건
재매각, 농지취득자격증명 필요 등 해당 물건에 붙는 특수 입찰 조건.

04

기능 요구사항

기능은 11개 모듈로 나눈다. 각 요구사항에는 참조용 ID를 붙였다.

4.1 데이터 수집 — 마이옥션 연동

  • FR-DATA-01

    마이옥션 계정(아이디/비밀번호)으로 로그인하여 관심물건 목록 페이지에 접근한다.

  • FR-DATA-02

    로그인 자격증명은 환경변수 또는 암호화된 로컬 저장소에 보관하며, 소스코드나 DB에 평문으로 남기지 않는다.

  • FR-DATA-03

    스케줄러는 설정된 주기(기본 1일 1회, 조정 가능)로 자동 수집을 실행한다.

  • FR-DATA-04

    사용자는 화면의 "지금 동기화" 버튼으로 수동 즉시 수집을 실행할 수 있다.

  • FR-DATA-05

    물건별 핵심 필드(사건번호, 소재지, 물건종류, 감정가, 최저매각가격, 매각기일, 진행상태, 유찰횟수, 면적 등)를 파싱해 저장한다.

  • FR-DATA-06

    수집 결과(성공/실패, 신규·변경·삭제 건수, 소요시간, 오류 메시지)를 동기화 이력으로 기록하고 조회할 수 있다.

  • FR-DATA-07

    이전 수집 결과와 비교해 신규 등록, 상태 변경(진행중→낙찰/취하 등), 가격 변경, 마이옥션에서 관심 해제된 물건을 감지한다.

  • FR-DATA-08

    로그인 실패나 페이지 구조 변경으로 수집이 실패하면 오류를 기록하고 알림으로 통지한다.

  • FR-DATA-09

    수집 주기, 재시도 횟수, 타임아웃은 설정 화면에서 조정할 수 있다.

4.2 메인 — 관심물건 목록

  • FR-MAIN-01

    메인 화면은 관심등록된 전체 물건을 카드 또는 테이블 목록으로 표시한다.

  • FR-MAIN-02

    항목별로 사건번호, 소재지(간략), 물건종류, 감정가, 최저매각가격, 매각기일(D-day 포함), 진행상태, 유찰횟수, 우선순위 태그를 표시한다.

  • FR-MAIN-03

    매각기일 임박순, 최저가율 낮은순, 감정가순, 관심등록일순으로 정렬할 수 있다.

  • FR-MAIN-04

    지역, 물건종류, 가격대, 진행상태, 우선순위 태그로 필터링할 수 있다.

  • FR-MAIN-05

    항목 클릭 시 상세 화면으로 이동해 전체 정보를 확인할 수 있다.

  • FR-MAIN-06

    물건별로 우선순위 태그(관심/검토중/입찰예정/포기/낙찰실패)와 자유 메모를 등록할 수 있다.

  • FR-MAIN-07

    매각기일이 7일 이내(조정 가능)로 임박한 물건은 시각적으로 강조한다.

  • FR-MAIN-08

    목록 상단에 요약 통계(전체 물건 수, 이번 주 매각 예정 수, 신규 수집 수)를 표시한다.

4.3 지도 뷰

  • FR-MAP-01

    지도 메뉴 진입 시 관심등록된 모든 물건의 위치에 핀을 표시한다.

  • FR-MAP-02

    각 핀에는 최저매각가격(또는 감정가)이 라벨로 함께 표시된다.

  • FR-MAP-03

    핀은 진행상태(진행중/유찰/낙찰/취하) 또는 유찰횟수에 따라 색상·아이콘을 달리한다.

  • FR-MAP-04

    핀 클릭 시 화면 우측(모바일은 하단) 사이드바에 해당 물건의 상세 정보가 표시된다.

  • FR-MAP-05

    다수 물건이 근접하면 클러스터링하여 표시하고, 확대 시 개별 핀으로 분리한다.

  • FR-MAP-06

    규제구역·개발단지 레이어를 지도 위에서 켜고 끌 수 있다. (4.5 참조)

  • FR-MAP-07

    목록과 동일한 필터(지역/종류/가격대/상태)를 지도에도 적용할 수 있다.

  • FR-MAP-08

    지오코딩에 실패한 물건은 별도 목록으로 표시해 주소를 수동 보정할 수 있게 한다.

4.4 물건 상세 사이드바

  • FR-DETAIL-01

    사건번호, 법원, 소재지(지번/도로명), 물건종류, 면적(대지/건물/전용), 층·방향을 표시한다.

  • FR-DETAIL-02

    감정가, 최저매각가격, 유찰횟수, 매각기일, 매수신청보증금(최저가의 10% 자동계산)을 표시한다.

  • FR-DETAIL-03

    임차인 현황 요약과 인수·소멸 권리 메모를 사용자가 직접 입력·저장할 수 있다. 자동 법률 판단은 제공하지 않으며 어디까지나 참고용 메모다.

  • FR-DETAIL-04

    마이옥션 원본 상세페이지와 법원경매정보(대법원) 링크를 제공한다.

  • FR-DETAIL-05

    사용자 메모, 우선순위 태그, 목표 입찰가를 입력·수정할 수 있다.

  • FR-DETAIL-06

    해당 물건의 임장 기록(방문일, 메모, 사진)을 추가·조회할 수 있다.

  • FR-DETAIL-07

    해당 위치가 어떤 규제구역·개발단지에 해당하는지 요약 배지로 표시한다.

  • FR-DETAIL-08

    가격·상태 변동 이력을 타임라인으로 표시한다.

4.5 규제 · 개발구역 지도 레이어

  • FR-ZONE-01

    규제구역 레이어를 개별 on/off 토글로 제공한다 — 투기과열지구, 조정대상지역, 토지거래허가구역, 개발제한구역(그린벨트), 정비구역(재개발·재건축·재정비촉진지구).

  • FR-ZONE-02

    개발 관련 레이어를 제공한다 — 택지개발지구·도시개발구역, 신도시 예정지(3기 신도시 등), 산업단지·경제자유구역, 역세권 개발(GTX·신설역) 반경.

  • FR-ZONE-03

    구역 데이터는 공공데이터 API(국토교통부, VWorld, 토지이용규제정보서비스 등)로 주기 갱신하여 로컬에 캐시한다.

  • FR-ZONE-04

    물건 상세 화면에서 해당 위치가 속한 규제·개발구역을 자동 판정(point-in-polygon)하여 배지로 표시한다.

  • FR-ZONE-05

    레이어 데이터의 출처와 갱신일자를 지도 범례에 표시한다.

4.6 알림

  • FR-ALERT-01

    매각기일이 N일 이내(기본 7일, 조정 가능)로 임박한 물건이 있으면 알림을 표시한다.

  • FR-ALERT-02

    가격(감정가/최저가) 또는 진행상태가 변경된 물건이 있으면 알림을 표시한다.

  • FR-ALERT-03

    신규 관심등록 물건이 수집되면 알림을 표시한다.

  • FR-ALERT-04

    스케줄러 실행 실패(로그인 실패 등) 시 알림을 표시한다.

  • FR-ALERT-05

    기본 채널은 웹 화면 내 알림함이며, 이메일 알림은 선택 기능으로 둔다.

4.7 임장 관리

  • FR-VISIT-01

    물건별로 임장 계획(예정일, 준비사항 체크리스트)을 등록할 수 있다.

  • FR-VISIT-02

    임장 완료 후 방문일, 현장 메모, 사진을 기록할 수 있다.

  • FR-VISIT-03

    기본 체크리스트(관리사무소 확인, 등기부등본 재확인, 실거주자 확인, 주차·일조·소음 확인 등)를 제공하고 항목을 추가·수정할 수 있다.

4.8 입찰 관리

  • FR-BID-01

    물건별 목표 입찰가와 입찰 예정일을 기록할 수 있다.

  • FR-BID-02

    매수신청보증금(최저매각가격의 10%, 재매각 등 특별조건 반영)을 자동 계산해 표시한다.

  • FR-BID-03

    같은 지역·유형 물건의 과거 낙찰가율 통계(수집 데이터 기반)를 참고 지표로 제공한다.

  • FR-BID-04

    입찰 결과(낙찰/패찰/유찰)를 기록해 이후 통계에 반영한다.

4.9 통계 · 필터 · 검색

  • FR-STAT-01

    지역별·물건종류별 관심물건 분포를 요약 통계로 제공한다.

  • FR-STAT-02

    평균 감정가 대비 최저가율, 평균 유찰횟수 등 요약 지표를 제공한다.

  • FR-STAT-03

    주소·사건번호 키워드 검색을 지원한다.

4.10 데이터 백업 · 내보내기

  • FR-EXPORT-01

    전체 관심물건 목록을 Excel(CSV) 형식으로 내보낼 수 있다.

  • FR-EXPORT-02

    DB 전체를 정기적으로 로컬 백업 파일로 저장할 수 있다.

4.11 계정 · 보안

  • FR-SEC-01

    웹앱 자체도 최소한의 로그인(단일 사용자 비밀번호 또는 기본 인증)으로 보호한다. 외부 네트워크에 노출할 경우 필수.

  • FR-SEC-02

    마이옥션 자격증명은 애플리케이션 DB와 분리된 비밀 저장소(.env, OS 키체인, 또는 암호화 필드)에 보관한다.

  • FR-SEC-03

    로그 파일과 화면 어디에도 비밀번호 평문이 노출되지 않는다.

외부 연동 상세

마이옥션

공식 API가 없다고 가정하고, Playwright 기반 헤드리스 브라우저로 로그인 후 관심물건 목록 페이지를 파싱한다. 사이트 구조 변경 리스크가 있으므로 CSS 셀렉터는 코드가 아닌 설정 파일로 분리해 관리한다.

지도 · 지오코딩

10

리스크 및 고려사항

약관 마이옥션 이용약관상 자동화 접근·스크래핑이 제한될 수 있다. 본인 계정, 개인적·비상업적 사용 목적임을 전제로 하고 과도한 요청 빈도(예: 1일 수 회 이상)는 피한다.

구조 변경 마이옥션 UI 개편 시 스크래퍼가 깨질 수 있다. 실패 알림(FR-ALERT-04)과 셀렉터 설정 분리(NFR-04)로 대응한다.

좌표 정확도 경매 물건 주소는 지번주소·구주소인 경우가 많아 지오코딩 실패율이 상대적으로 높을 수 있다. 수동 보정 UI(FR-MAP-08)가 필요하다.

데이터 최신성 투기과열지구 등은 정부 고시로 수시 변경된다. 자동 API가 없는 항목은 반기·분기별 수동 갱신 프로세스를 둔다.

계정 보안 마이옥션 자격증명과 웹앱이 같은 개인 서버에 있으므로, 외부 노출 시 보안 사고 리스크가 있다. 방화벽·VPN 또는 리버스프록시+인증을 권장한다.
